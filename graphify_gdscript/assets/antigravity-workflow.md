# Workflow: graphify-gdscript

Follow the graphify-gdscript skill.

With no arguments, run `graphify-gdscript scan` for the current project and summarize the result. Otherwise treat the arguments as a skill command such as `query "<question>"`, `trace "<signal>"`, `path "<A>" "<B>"` or `explain "<symbol>"`.
